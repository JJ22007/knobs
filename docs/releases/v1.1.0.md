# Knobs 1.1.0

Knobs is now a settings layer an agent can drive and you can check: every change is read back, explained and undoable, from the command line, from an MCP client or from the window.

## New

- **Undo for every change.** `knobs set`, `reset`, `apply`, a click in the window and an agent's write all save a snapshot first. `knobs undo` steps back one change at a time (`knobs undo --list` says what each step undoes). The window has an Undo button (⌘Z), and so does the menu.
- **`knobs mcp`, an MCP server.** It has the same catalog and the same checked writes as the command line. It is read-only unless you start it with `--allow-write`, and dry runs always work. Each write returns the value before and after, whether macOS confirmed it, and when it takes effect.
- **`--json` and `--dry-run` everywhere.** Every reporting command can answer in JSON. `takesEffect` is `instant`, `newWindows` or `relogin`, with the plain words next to it.
- **`knobs verify`.** A read-only check of every key already written on this Mac against the catalog: right type, in range, one of the listed choices. Unset keys are counted, not guessed.
- **Scenes and `knobs scene present`.** A scene is a profile that can also drive the author's other tools through their own agent interfaces:
  - **Overbright** sets the built-in display's brightness, and the panel's reading proves it arrived.
  - **Paneful** arranges windows and reads every frame back.

  `present` keeps the display on, clears the desktop and Dock, turns hot corners off and lifts the brightness to 130%. `examples/present-keynote.knobs.json` also makes the Keynote window fill the screen. One `knobs undo` restores the settings, the brightness and the windows.

## Changed

- Batches are all or nothing: if one value is refused, nothing is written.
- Snapshots are written owner-only (`0600`), 50 at most. Paths in output use `~` instead of your home folder.
- `build.sh install` asks before writing the Claude Code skill (`KNOBS_SKILL=1` or `0` answers ahead of time). A skill that is already installed is refreshed.
- The personal example profile moved out of the bundled presets into `examples/`.
- New: SECURITY.md (what Knobs changes and keeps, and how to report a problem) and issue templates.

## Corrections to the 1.0.0 notes

- "Keep the display awake without `sudo`" was listed as a highlight. It isn't one: `caffeinate` and other keep-awake apps don't need `sudo` either.
- "A Claude Code skill installed with the app": the installer now asks first.

## Install or update

```bash
curl -fsSL https://raw.githubusercontent.com/JJ22007/knobs/main/scripts/bootstrap.sh | bash -s -- snappy
```

It is built from source on your Mac, so Gatekeeper has nothing to block. There is no notarized download yet. Tested on macOS 27.2.1.
